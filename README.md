# PLataforma de visualización de la aplicación:

https://noe-osorio-garcia.shinyapps.io/Geomatica_UNAM/

Este proyecto fue realizado para el Diplomado en Geomática, considerando la evaluación de buffers e Isocronas para el análisis de incidencia, evaluando la cantidad de delitos a través del tiempo en esa zona así como 
la correlación con otros delitos. 
La app también integra los elementos para evaluarla en el entorno inmediato (ISocronas caminando) en un periodo de 5,10 y 15 minutos a través del algoritmo h3
